Which rows are hidden as "not applicable"?

Rows are hidden only by device definition, never because a value is blank. A row is hidden only when it is not applicable to every selected model and none of them has a value in it; if any selected model has a value, the row is shown. Tick "Show all attributes" to see every row. Hidden rows are not counted as differences.

  • Pacemaker, CRT-P, Leadless: Max energy, ATP during charging, SVT discrimination (shock-therapy only).
  • ICM: Max energy, connector ports, NBG/NBD code, CRT optimization, multipoint LV, LV quadripolar, pacing algorithms, capture management, rate-response sensor, ATP during charging, SVT discrimination.
  • Single-chamber (ICD single chamber incl. DX, single-chamber pacemakers, leadless, S-ICD/EV-ICD): CRT optimization, multipoint LV pacing, LV quadripolar.
  • S-ICD/EV-ICD: rate-response sensor (no rate-responsive bradycardia pacing). Other pacing rows are kept because EV-ICD provides ATP/pause-prevention pacing.
  • S-ICD only: ATP during charging and capture management (S-ICD delivers no ATP or bradycardia pacing beyond post-shock pacing). EV-ICD keeps these rows.
  • Noise/oversensing algorithms are never hidden (pacemakers have noise reversion too). Leads are never hidden.
